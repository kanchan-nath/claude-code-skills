# Review checklist (self-critique, and critiquing someone else's prompt or clip)

Run silently before delivering any prompt pack. When the user gives you a prompt or a generated clip to critique, run it as a diagnosis and then rewrite.

## 1. Hard-ban pass (any hit = P0, unless brand-supplied)

- [ ] No eyebrow/kicker label, stacked tagline, "Introducing...", text wall, or filler text (decorative captions, fake metrics, lorem).
- [ ] No serif, no italic/oblique/skewed text.
- [ ] No orange/amber/beige/cream/tan/sand; no neon, glow, bloom, halo; no purple/violet/indigo or multi-hue gradient; no glassmorphism.
- [ ] No emoji or stock icons; no sparkles for AI, particles, confetti, lens flares, code rain.
- [ ] No bouncy overshoot except <= 2 true landings.

## 2. Director's questions (answer each with a shot number)

1. The weakest 3 seconds - which, and why?
2. Anything cheap, templated, slow, confusing or dead? (Check against look-and-personality.md section 8.)
3. Specificity: would the film be just as true of a simpler product? Name the non-obvious behaviour and the beat that shows it.
4. Its own look: does it match the three adjectives? Or does it look like a generic minimal tech template? Is the palette a default (framework blue on flat grey, pure black/white)?
5. Colour with character: at thumbnail size does a mid-film frame show the brand colour carrying the action?
6. Does each shot's idea land in under 1 s?
7. Does it read with the sound off? Does the device never blink out and end as the mark (or the resolved unit)?
8. The hook: frame 0 composed and moving; problem felt by 1 s, stated by 2 s; not a logo, blank frame or "Introducing...".
9. Can a stranger name the product and the feature? (Feature named once; enough app chrome to read as software.)
10. The end: lockup resolved 1.5-2.0 s and building; URL/date readable >= 1.7 s if the brief gave one; the last frame works as a poster.
11. Pacing: one motion peak per bar, calm between peaks, first 6 s about twice as dense as the middle, last biggest peak at 75-90%, no sag after the turn.
12. Transitions: 6-8 types, none more than twice, one signature move at open/middle/close, crossfade not the default.

## 3. Concept tests (concept-and-copy.md section 4)

Ownership, deletion, muted, feature word, poster, one sentence, retell, specificity, budget, truth. A concept that fails ownership or deletion is out however pretty.

## 4. Prompt-quality checks

- [ ] Style Bible present and IDENTICAL in every shot prompt.
- [ ] One main action per shot; a stated rest state; motion described with easing words; camera stated.
- [ ] Exact on-screen words in quotes, within budget (<= 5 words/line, <= 2 lines/shot), or "no text".
- [ ] Negative block included (or positive equivalents).
- [ ] Beat table: seconds, picture, text, sound, seam.
- [ ] Word total within the format budget; line test passed for every line.
- [ ] Key frames, music prompt and edit notes included.
- [ ] Anything a generator cannot do reliably (exact text, logo, counters, perfect loops, beat-sync) is assigned to the editor, and the user is told.

## 5. Severity

P0: visible on a key beat (hook, payoff, logo) or breaks the story, or a hard ban. P1: noticeable on a normal viewing. P2: visible only when paused. Fix in order of impact per minute.

## 6. Critiquing a generated clip (user pastes a prompt or describes the result)

Diagnose with the symptom table in prompt-templates.md section 7, name the P0/P1 issues with shot numbers, then give the rewritten prompt (not general advice). Rewrite for fewer simultaneous motions, a clear rest state, a pasted Style Bible, and an explicit negative block.

## 7. Stop rule

Iterate until no P0 is open and the director's questions all have a good answer; usually two rounds. State plainly what you would still change.
