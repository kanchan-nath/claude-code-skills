# Extras (only when the user asks)

## Contents
1. Titles
2. Description and pinned comment
3. Hashtags
4. On-screen text and B-roll notes
5. 30-second cut
6. Re-hooks for slightly longer Shorts
7. CTA variations

## 1. Titles

- Keep under 60 characters.
- Put the main keyword in the first 40 characters.
- Add a curiosity or benefit word.
- Give 3 options unless the user asks for one.

Examples:
- "16 AI Coding Tools When Claude Limit Ends"
- "AI Bubble Burst: Will Jobs Be Safer?"

## 2. Description and pinned comment

- Line 1: the hook idea in one sentence.
- Line 2: the resource or link, with a plain label.
- Line 3: one CTA.
- Keep it short. Do not stuff keywords.
- If the script says "link in the description", make sure the link appears there.

## 3. Hashtags

- 3 to 5 relevant tags. Mix one broad and the rest specific.
- Example: #AItools #coding #developers #shorts #learntocode

## 4. On-screen text and B-roll notes

- Mirror the hook as big text in the first frame.
- Show tool logos or names as they are spoken.
- Show a screen recording for the experience block (the real chat, the real tool).
- Use a quick visual change every 3-5 seconds.
- Put notes in square brackets next to the spoken line.

## 5. 30-second cut

- Keep: hook, one-line problem or question, one-line experience, takeaway, short CTA.
- Cut: resource lines, examples, secondary explanation.
- Target 65-80 spoken words.

## 6. Re-hooks for slightly longer Shorts

If a script crosses ~40 seconds, add a mid-script pattern interrupt:
- "Now here's the part most people miss."
- "But wait, there's a catch."
- "And this is where it gets useful."

## 7. CTA variations

- Question first: "Which one will you try first? Tell me in the comments."
- Value-based subscribe: "Subscribe, so you don't miss the next tool."
- Save-based: "Save this so you have it when your limit ends."
- One CTA is best; two is the limit.
